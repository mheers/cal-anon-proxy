<objective>
Fix the three interrelated bugs in calendar.go: the data race on CalDavHandler.Backend, the missing empty-slice guard in calendarBackend.Calendar(), and the stub QueryCalendarObjects that returns nil for all REPORT requests.

Purpose: CalDAV clients (Apple Calendar, Thunderbird) currently see empty calendars because QueryCalendarObjects returns nil, nil. The data race means go test -race fails. These are all in one file and share structural changes to SetEvents.

Output: A thread-safe CalDavHandler where SetEvents stores individual CalendarObjects per event, QueryCalendarObjects filters correctly via caldav.Filter, and all slice accesses are guarded.
</objective>

func (b *calendarBackend) QueryCalendarObjects(
    ctx context.Context,
    path string,
