From github.com/emersion/go-ical (ical.go):

```go
// ValueType constants
type ValueType string
const (
    ValueDate     ValueType = "DATE"
    ValueDateTime ValueType = "DATE-TIME"
)

// Prop methods
func (prop *Prop) ValueType() ValueType      // reads VALUE= param; falls back to default
func (prop *Prop) SetDate(t time.Time)        // writes VALUE=DATE format
func (prop *Prop) SetDateTime(t time.Time)    // writes VALUE=DATE-TIME format
func (prop *Prop) DateTime(loc *time.Location) (time.Time, error)  // parses both DATE and DATE-TIME
```

Key insight: `prop.ValueType() == ical.ValueDate` is the correct guard for all-day events.
`ical.ValueDate` = `"DATE"` (the `VALUE=DATE` parameter string).

For `harmonizeDurationAndEnd`: when both DTEND and DURATION are absent, set DTEND = DTSTART
using `event.Data.Children[x].Props.SetDateTime(ical.PropDateTimeEnd, startTime)`.
The `startTime` is already computed from `start.DateTime(time.UTC)`.

For EXDATE/RECURRENCE-ID: add two string literals to the `Props` slice in `QueryCalendar`.

**Fix 1: toTZ — add VALUE=DATE early return (REQ-05)**

In `toTZ()` (line 234), after the nil-prop check and before the MS timezone translation,
add a VALUE=DATE guard:

```go
func toTZ(event *caldav.CalendarObject, x int, tz *time.Location, propName string) error {
    eventProps := event.Data.Children[x].Props
    prop := eventProps.Get(propName)
    if prop == nil {
        return fmt.Errorf("property %s not found for event %s", propName, summaryOfEvent(event))
    }
    // All-day events use VALUE=DATE — skip timezone conversion, preserve as-is
    if prop.ValueType() == ical.ValueDate {
        return nil
    }
    // ... existing code continues unchanged ...
```

This guard must come AFTER the nil check but BEFORE `prop.Params.Get(ical.PropTimezoneID)`.
No other changes to `toTZ`.

**Fix 2: harmonizeDurationAndEnd — zero-duration case (REQ-06)**

In `harmonizeDurationAndEnd()` (line 256), the current code returns an error when both
DTEND and DURATION are absent. Replace the two error returns for missing/empty DURATION with
a zero-duration treatment:

Current (lines 269–274):
```go
duration := eventProps.Get(ical.PropDuration)
if duration == nil {
    return fmt.Errorf("duration not found for event %s", summaryOfEvent(event))
}
if duration.Value == "" {
    return fmt.Errorf("duration not found for event %s", summaryOfEvent(event))
}
```

Replace with:
```go
duration := eventProps.Get(ical.PropDuration)
if duration == nil || duration.Value == "" {
    // Zero-duration event: DTSTART only, no DTEND or DURATION — RFC 5545 §3.6.1 valid case
    // Set DTEND = DTSTART so downstream processing and clients handle it correctly
    event.Data.Children[x].Props.SetDateTime(ical.PropDateTimeEnd, startTime)
    return nil
}
```

Note: `startTime` is already computed a few lines above (`startTime, err := start.DateTime(time.UTC)`).
The SetDateTime call must come AFTER the `startTime, err := start.DateTime(...)` line.
